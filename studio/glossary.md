# Словарь студии

Черновик. Термин фиксируется, когда начинает использоваться в документах; определение
уточняется вместе с концепцией. Термины OMIXFlow не переносятся автоматически.

| Термин | Значение |
|---|---|
| студия | весь проект: сервер, клиентская часть, трекер, UI |
| сервер | общий для команды процесс студии: хранит состояние, собирает и ведёт пайплайны |
| клиент | среда, в которой разработчик работает с агентами (Claude Code и подобные), связана с сервером через MCP |
| агент | модель, исполняющая шаги пайплайна в клиенте |
| пайплайн | определение процесса разработки задачи, собранное под проект |
| прогон | исполнение пайплайна по конкретной задаче |
| шаг | единица прогона, которую агент получает от сервера и исполняет |
| точка решения | место прогона, где нужно решение человека или координатора |
| трекер | часть студии, ведущая задачи; встроен в пайплайн |
| задача | единица работы в трекере; к ней привязаны прогон, артефакты, решения |
| артефакт | результат шага, хранимый студией (постановка, исследование, план и т. п.) |
