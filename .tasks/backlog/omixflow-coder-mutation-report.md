**Контекст.** Третий прогон лида, `add-snake-case`, Implement шаг 1 и Review.

**Проблема.** Coder записал в отчёт шага 1 «каждая мутация роняет тест»
(`.tasks/add-snake-case/log.md:46`). Reviewer нашёл три выживших мутанта:
`nxt.islower()` → `not nxt.isupper()` (F2) и ещё два на шаге 2 (F4); оркестратор
поправил запись (`log.md:70`). Обобщённый отчёт скрывает непроверенные мутации,
и их ловит только ревью.

**Предложение.** В NOTES отчёта coder перечисляет мутации списком
«мутация → упавший тест»; формулировки вида «каждая мутация» запрещены.

**Критерии приёмки.**
- Формат отчёта coder (`agents/coder.md`) содержит список мутаций с тестами.
- Оркестратор Implement сверяет список с числом новых проверок.
