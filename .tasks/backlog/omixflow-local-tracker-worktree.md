# OMIXFlow: Refine с трекером `local` пишет в основное дерево

- **Репозиторий:** omixflow (`skills/refine`, `skills/start`, `adapters/tracker/local.md`)
- **Происхождение:** живой прогон лида 2026-10-04 (песочница `omixflow-sandbox`, задачи
  `add-slugify` и `add-truncate`, `--worktree`), гоча обеих сессий.
- **Тип:** Bug
- **Тир:** S
- **Статус:** закрыто 2026-10-06 без правки: проектам, которым мешает запись трекера
  в основное дерево, ответ — трекер `kanban` (0.4.0, доска на своей ветке); `local` остаётся
  как есть.

## Проблема

Refine пишет уточнённую формулировку через `update_description` адаптера `tracker/local`,
то есть правит `{tracker.dir}/{id}.md` в текущем дереве. До Start это основное дерево на
базовой ветке, а она обычно в `workspace.protected`: коммитить туда нельзя. Worktree задачи
создаётся от HEAD базы и правки Refine не видит, а Start читает «Уточнённую формулировку»
именно из описания. Обе сессии прогона переносили файл в ветку задачи вручную (`cp`
в worktree, затем `git checkout -- {path}` в основном дереве). Скил `refine` при этом
заявляет «никаких локальных файлов», что для `tracker/local` неверно по определению.

## Предлагаемое решение

- `skills/start`, шаг 2: при `tracker.adapter: local` и незакоммиченной правке
  `{tracker.dir}/{id}.md` (и индекса) в основном дереве перенести её в ветку задачи
  (worktree или новая ветка) и вернуть основное дерево к HEAD только по этим путям;
  записать перенос в log.md.
- `skills/refine`, «Правила»: оговорка для `tracker/local` (запись в файл дерева, коммит
  в ветке задачи на Start).

## Критерии приёмки

- Задача с `tracker: local` и `--worktree` от защищённой базы: после Start уточнённая
  формулировка закоммичена в ветке задачи, основное дерево чистое.
- Без `--worktree` поведение прежнее: правка остаётся в дереве и коммитится на Start.
